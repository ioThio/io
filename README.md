# io

An early WordPress block theme experiment exploring Full Site Editing and configuration through `theme.json`.

## Project status

This 2022 prototype is retained for review and future development. It contains an initial theme configuration and a minimal index template; it is not a complete production theme.

Compatibility with current WordPress and PHP versions has not been verified.

## What is included

- `theme.json` — color palettes, typography, layout, spacing, and block styling settings.
- `templates/index.html` — a minimal template containing the Site Title block.
- `style.css` — the WordPress theme header and original compatibility declarations.
- `screenshot.png` — the original theme screenshot.
- `LICENSE` — the repository license.

The original theme header declares WordPress 5.9 or later, testing up to WordPress 6.0, and PHP 8.0 or later. These are historical declarations, not current compatibility test results.

## Exploring the prototype

Use a local or disposable WordPress installation to inspect the theme files and Site Editor behavior. Further template development and testing are needed before considering live use.
